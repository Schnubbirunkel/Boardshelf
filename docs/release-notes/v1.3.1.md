**Boardshelf 1.3.1**

- Barcode-Scanner: Wenn du nach dem Scannen ein Spiel auswählst, wird die Zuordnung an GameUPC zurückgemeldet (die Datenbank wird gemeinsam gepflegt, zwei übereinstimmende Meldungen machen eine Zuordnung verlässlich).
- Korrigierter Hinweis in den Einstellungen: GameUPC hat keine Anmeldung, ein eigener Schlüssel ist nicht nötig.
- Kopfzeile im Barcode-Ergebnis zeigt den GameUPC-Treffer statt „nicht gefunden“.
