**Boardshelf 1.3.0** – Barcode-Scanner, KI-Cover, neues Design

### Neu
- **Barcode-Scanner**: Barcode auf der Schachtel scannen → das Spiel wird erkannt und samt Cover angelegt. Quellen: GameUPC (Brettspiel-Barcodes inkl. europäischer Ausgaben), UPCitemdb, Open Products Facts, Wikidata.
- **Kein BoardGameGeek-Konto mehr nötig**: Spieldaten kommen aus Wikidata/Wikipedia, Barcodes aus GameUPC. Ein BGG-Token ist nur noch optional.
- **Automatische Cover-Vorschläge** aus mehreren Quellen, die besten werden automatisch übernommen.
- **KI-Bilderkennung (optional)**: Claude, Gemini, ChatGPT oder ein selbst gehostetes Modell (Ollama, LM Studio …) prüft Cover-Vorschläge (Vorderseite? Richtiges Spiel?), schneidet sie automatisch zu und erkennt Spiele auf einem **Foto der Schachtel**.
- **Mehrere Fotos pro Spielstand**: beliebig viele Fotos aus Kamera oder Galerie (Mehrfachauswahl), Wischen durch die Fotos, nachträglich ergänzen oder entfernen.
- **Neues Design** im Stil von Liquid Glass / One UI: Glas-Flächen über einem fließenden Hintergrund, große Überschrift, die beim Scrollen in die Leiste wandert, schwebende Glas-Leiste mit Suchen / Scannen / Hinzufügen, Glas-Tabs, federnde Animationen.

### Geändert
- 3D-Schachtel: Hoch- und Runterziehen ist jetzt umgekehrt (natürlichere Drehrichtung).

### Hinweis
Installiert direkt über 1.2.1 – deine Daten werden automatisch übernommen.
